# Halfshaft: сайт автосервісу

Статичний багатосторінковий сайт: кожна сторінка є окремим HTML з власною адресою. Компоненти на TSX рендеряться під час збірки, у браузері працює лише невеликий JS (меню, фільтри прайсу, розрахунок, заявка). Зовнішніх бібліотек на сторінках немає.

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev       # збірка + локальний сервер http://localhost:4321 з перебудовою при змінах
npm run build     # збірка в dist/
npm run preview   # віддати dist/ без перебудови
npm run check     # перевірка типів + битих посилань і зображень у dist/
```

## Що де редагувати

| Що | Файл |
|---|---|
| Назва, адреса, години, контакти, правила запису, індексація | `src/data/business.ts` |
| Каталог послуг, тексти сторінок послуг, симптоми | `src/data/services.ts` |
| Прайс (суми, одиниці, запчастини) | `src/data/prices.ts` |
| Кольори, шрифти, відступи | `src/styles/tokens.css` (усі значення тут; `site.css` бере лише токени) |
| Логотип | `assets/brand/` (SVG), генератор `tools/make_logo.py` |

Ціни на головній, сторінках послуг, у прайсі й у формі заявки беруться з одного файлу `prices.ts`. Збірка зупиниться з помилкою, якщо рядок прайсу посилається на неіснуючу послугу.

**Контакти.** Телефон, e-mail, мапа й месенджери за замовчуванням `null`, і сайт їх не показує. Щойно задасте значення в `business.ts`, вони з'являться в підвалі й на сторінці контактів.

**Індексація.** Дані вигадані, тому `site.indexable: false`: на сторінках стоїть `noindex`, а `robots.txt` закриває сайт. Для справжнього бізнесу замініть дані, вкажіть `site.url` і поставте `true`. Розмітка LocalBusiness вмикається окремим прапорцем.

## Фото

На сайті три фотографії. Список і джерела в `assets/images/images.json`.

| Слот | Де видно | Зараз |
|---|---|---|
| `hero-bay` | головна, перший екран; картинка для соцмереж (`og.png`) | автомобіль на підйомнику, Shixart1985, CC BY 2.0 |
| `mechanic` | головна (блок «Записатися») і «Про нас» | механік біля підвіски, Shixart1985, CC BY 2.0 |
| `bench` | головна на всю ширину і «Про нас» | верстак з інструментом, Petar Milošević, CC BY-SA 4.0 |

Під час збірки фото завантажуються з Wikimedia Commons і кешуються в `.cache/`. Автор і ліцензія автоматично виводяться в підвалі кожної сторінки. Якщо мережі немає, збірка ставить сіру заглушку й не падає.

**Своє фото.** Покладіть `assets/images/<слот>.jpg` (або `.jpeg/.png/.webp`), наприклад `hero-bay.jpg`. Воно має пріоритет над Commons, рядок про автора з підвалу зникне сам. Збірка робить WebP потрібних ширин, а у назві файлу є ключ від вмісту, тож браузери не покажуть старе фото з кешу. Кадрування для телефона (`narrow`: пропорція й точка фокусу) задається в `images.json`.

Усі фото показуються чорно-білими з контрастом (фільтр у `site.css`), тому кольорові кадри теж підійдуть.

## Онлайн-заявка

`booking.mode` у `business.ts`:

- `"local"` (зараз): бекенду немає. Заявка зберігається в `localStorage` браузера відвідувача, і сайт прямо каже про це ще до відправки. У майстерню вона **не надходить**.
- `"endpoint"`: заявка йде `POST`-запитом із JSON на `booking.endpoint` із заголовком `Idempotency-Key`. Сайт показує «Заявку надіслано» і пояснює, що це ще не підтверджений запис. На помилку чи таймаут (15 с) показує повідомлення й зберігає введені дані.

Доступні дати й час рахуються з `hours` і `booking` (крок слотів, останній слот до закриття, запас годин, святкові дні) за київським часом.

## Хостинг

У `dist/` лежать звичайні файли. `vercel.json` уже налаштований (`cleanUrls`), тож `/pricing` віддає `pricing.html`, а невідомі адреси отримують `404.html`. Netlify і Cloudflare Pages так само працюють без налаштувань.
